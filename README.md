# 📅 日历习惯与重复事项管理系统 (Daily Routine Tracker)

基于 **Nuxt 3 + SQLite + Tailwind CSS** 构建的移动端优先（Mobile-first PWA App 体验）日历重复事项与自律打卡管理系统。

---

## 🌟 核心功能亮点

### 1. 移动端 App 原生体验
- 底部 TabBar 沉浸式导航（适配 iOS / Android 底部安全区 Safe Area）。
- 支持全屏 Web App 模式（可“添加到主屏幕”当独立 App 使用）。
- 灵敏触摸反馈、一键打卡与全任务达成彩带庆祝动画（Confetti）。

### 2. 账号密码认证体系
- 基于 SQLite + JWT Cookie 会话的安全认证系统。
- 注册新账号后，**自动注入预置任务模板**（开箱即用）。

### 3. 三大核心面板架构
- **面板 1：今日事项打卡与状态修改 (`/`)**
  - **GitHub 风格打卡热力方格图 (Heatmap)**：支持查看近 16 周的打卡活跃度与满卡率（深浅绿格），点击任意格子可直接切换日期。
  - **日期快速切换**：支持回溯历史日期补卡，或提前查看未来任务。
  - **今日达成进度条**：直观展示已完成百分比与待办统计。
  - **分类过滤标签**：支持按全部、待办、学习跟读、运动、健康用药、自律戒断快速筛选。
- **面板 2：历史完成事项与数据统计 (`/history`)**
  - **自律火种**：当前连续打卡天数（Streak）、累计打卡总次数。
  - **阅读专属看板**：累计阅读总页数、阅读总时长、读过书单数。
  - **运动专属看板**：累计锻炼时长、运动次数与单次平均用时。
  - **事项完成榜单**：各事项累计完成频次与最近打卡日期。
  - **历史记录明细流**：按类别检索每一次打卡的详细备注、书名页码与心得。
- **面板 3：事项管理与增删改查 (`/manage`)**
  - 自定义事项创建与编辑（支持图标、色彩、时段、分类、重复规则配置）。
  - 内置丰富预设模板（一键套用）。

### 4. 专属任务类型支持
| 任务类型 | 典型场景 | 交互特性 |
| :--- | :--- | :--- |
| **时段任务 (`time_slot`)** | 每天 08:00 - 08:30 英语跟读 / 08:30 - 09:30 跑步 | 显示时间段胶囊徽章，支持快速一键打卡与时长统计 |
| **自由定量 (`quantified_log`)** | 自由时间阅读 | 弹窗记录书名（支持历史书目快捷点选）、起止页码（自动计算总页数）、耗时分钟与感悟 |
| **自律断舍离 (`abstinence`)** | 某天不吃晚饭 / 不吃零食 / 不喝汽水 | 盾牌自律徽章，记录坚持自律天数与抵制诱惑打卡 |
| **常规打卡 (`check_only`)** | 喝水、早起等日常习惯 | 标准一键打卡 |

## 🚀 启动与开发

### 安装依赖
```bash
pnpm install
```

### 启动本地开发服务
```bash
pnpm dev
```
启动后在浏览器或手机浏览器打开：`http://localhost:9990` (或服务器/局域网 IP 如 `http://43.153.145.181:9990`)

### 生产构建与运行
```bash
pnpm build
node .output/server/index.mjs
```

---

## 🗄️ 数据库说明
- 数据自动保存在 `server/data/routine.db`（SQLite 单文件数据库，支持自动建表与升级）。
- 数据支持单文件复制备份与迁移。
